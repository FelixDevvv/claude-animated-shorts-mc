# Pueblo 3:17 — RobloxPerson story video

This example uses the repository's default RobloxPerson character design and follows the 3D Shorts skill rules: vertical 9:16 framing, cinematic camera changes, grounded character motion, readable captions, and a short narrative arc.

Story: Mateo, a villager, follows the bell that rings once at 3:17 every night and discovers a mysterious note inside the old tower.

The Francarlos asset is not used. This example intentionally uses the default procedural RobloxPerson character.

The local render can be reproduced with Python + Matplotlib + FFmpeg from `render_pueblo.py`. The production character source remains `references/models/roblox-person/roblox-person.ts`.
