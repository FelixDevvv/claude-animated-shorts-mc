# Francarlos video reference

Source video supplied for this project:
`En Este Pueblo... YA NO QUIERO SEGUIR! 😭 parte 2 - Brena Extra (720p, h264).mp4`

The reference is 720p x 1280 at 30 fps and about 138.8 seconds long.

Representative frames should be generated into this directory with:
`python scripts/extract-francarlos-reference.py <video>`

Generated targets:
- francarlos_01.jpg ... francarlos_12.jpg
- ../sheets/francarlos_sheet.jpg

These are **visual references only** for posing, camera, lighting, framing and environment. They are not the source for the character geometry.
